# Участие в проекте TextFormatter

Спасибо за интерес к проекту! Прежде чем начать, пожалуйста,
прочитайте это короткое руководство.

## Коротко

- **Изменения кода не принимаются.** Проект проприетарный
  (см. [LICENSE](LICENSE)), исходный код закрыт.
- **Отчёты об ошибках и предложения функций приветствуются** через
  GitHub Issues.
- **Проблемы безопасности** — только через приватные каналы из
  [SECURITY.md](SECURITY.md), никогда через публичные issues.
- **Русский и английский языки** оба принимаются в issues.

## Что вы можете сделать

### 🐛 Сообщить об ошибке

Откройте новый issue:
**https://github.com/iinquisitor/TextFormatter/issues/new**

Пожалуйста, приложите:

- **Версия приложения** — видна в заголовке окна или в
  **Настройки → Об авторе**.
- **Операционная система** — Windows / macOS / Linux, плюс версия.
- **Шаги воспроизведения** — что вы делали, в каком порядке.
- **Ожидаемое поведение** — что должно было произойти.
- **Фактическое поведение** — что произошло на самом деле.
- **Скриншоты или короткое видео**, если баг визуальный.
- **Логи или ошибки**, если применимо. В релизах отладка отключена,
  однако вы можете запустить программу через `PowerShell`,
  смотреть пункт [`#Отладка`](#отладка).

Если баг воспроизводится только с определённым файлом, приложите
**минимальный пример** (несколько строк, вызывающих проблему). Не
вставляйте весь свой конфиг — сократите его.

### 💡 Предложить функцию

Откройте новый issue с меткой `улучшение` или `enhancement`:
**https://github.com/iinquisitor/TextFormatter/issues/new**

В запросе опишите:

- **Какую задачу** решит функция.
- **Как вы её себе представляете** в работе.
- **Почему существующие возможности** не покрывают вашу потребность.

Запросы рассматриваются по существу — не каждая идея будет
реализована, но каждая будет прочитана и рассмотрена.

### 🌐 Помочь с переводами

Приложение поддерживает русский и английский. Если хотите добавить
новый язык — сначала откройте issue для обсуждения, затем я
подготовлю список строк для перевода. Переводы принимаются в
комментариях к issue или текстовым файлом.

### 📣 Рассказать о проекте

- Поставьте звезду репозиторию:
  **https://github.com/iinquisitor/TextFormatter**
- Поделитесь с друзьями, которые держат серверы Minecraft
- Напишите о приложении на форумах / в Discord / на Reddit
- Сообщайте об ошибках — это реально помогает

## Что вы не можете делать (по условиям лицензии)

- **Отправлять pull request'ы с изменениями кода.** Проект закрытый.
  Любой PR будет закрыт без слияния. Это не личное — это требование
  лицензии.
- **Форкать и распространять.** Лицензия запрещает
  распространение. Вы можете поделиться **ссылкой** на официальную
  страницу релизов, но не самим бинарником.
- **Публиковать изменённые сборки.** По той же причине.
- **Продавать приложение или производные продукты.** Если нужна
  коммерческая лицензия — свяжитесь со мной напрямую.

## Отладка

Чтобы увидеть ошибки в консоли при сообщении о баге:

**Windows:** нажмите `Ctrl + Shift + I` — в релизных сборках
devtools отключены, поэтому понадобится **debug-сборка** или
собственный лог приложения.

Если нужны подробные логи, запустите приложение из терминала:

```powershell
# Windows
.\TextFormatter.exe 2> app.log
```

Затем приложите `app.log` к вашему issue.

## Язык
- **Русский и английский** оба принимаются в issues и комментариях.
- Фрагменты кода, сообщения об ошибках и пути к файлам могут быть
  на любом языке.

## Кодекс поведения
- **Будьте уважительны**. Это хобби-проект, который поддерживает один
  человек в свободное время. Основы:
- **Будьте терпеливы**. Ответы могут быть медленными — обычно в
  течение недели.
- **Будьте конкретны**. «Не работает» — это не баг-репорт;
  `«Я нажимаю Ctrl+S с файлом test.yaml, ничего не происходит,
  ожидал сохранения файла»` — это баг-репорт.
- **Никакой травли, дискриминации или личных нападок**. Нарушители
  будут заблокированы.
- **Никакого спама и офф-топик продвижения**. Только темы, связанные
  с приложением.
- **Уважайте лицензию**. Не просите обойти её; не предлагайте
  распространять бинарник.

Используйте приватные каналы из SECURITY.md.
