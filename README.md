# TextFormatter

Утилита для владельцев Minecraft-серверов, которая превращает обычный текст 
в «малые заглавные» буквы (small caps) с сохранением всех цветовых кодов и 
тегов плагинов.

## Что это

Редактор конфигов для Minecraft с двусторонним форматированием: вводишь текст 
слева — справа видишь его отформатированную версию. Форматирование 
реверсивное — из результата обратно в исходник, с автоматическим определением 
языка (RU/EN/UA) по контексту.

В отличие от «просто замены букв» и онлайн-конвертеров, TextFormatter 
**понимает контекст Minecraft**:

- не ломает `&0`–`&f`, `&k`–`&o`, `&r` — коды остаются на месте;
- защищает HEX-цвета `&#RRGGBB` и `<#RRGGBB>`;
- не трогает плейсхолдеры `%player%`, `{name}` и подобные;
- работает с тегами MiniMessage: `<color:#ff0000>…</color>`, 
  `<gradient:…>…</gradient>`, `<red>`, `<bold>`, `<obfuscated>` и другими;
- распознаёт escape-последовательности (`\n`, `\t`, `\uXXXX`) и не 
  трансформирует буквы внутри них.

## Возможности

### Редактор
- **Два поля** — ввод и результат, с автоматическим форматированием по мере 
  набора (можно отключить).
- **Реверс** — кнопка «←», которая восстанавливает исходный текст из 
  отформатированного.
- **Снимок оригинала** — кнопка «↩️ Вернуть» возвращает текст до последнего 
  форматирования (даже после сохранения).
- **Подсветка кодов Minecraft** прямо в редакторе: `&c` отображается красным 
  цветом, `&l` — жирным, `&#FF0000` — hex-цветом, `<gradient>` — плавным 
  переходом посимвольно.
- **Поле результата — read-only** и показывает текст «как в игре»: цветовые 
  коды скрыты, но при копировании возвращаются в текст.
- **Синхронизация прокрутки** между полями, зеркальная подсветка активной 
  строки, мини-карта документа, номера строк, поиск с заменой (Ctrl+F).

### Файлы и workspace
- **Открытие папки** как рабочего пространства: дерево файлов с 
  drag-and-drop, иконки по типу (YAML/JSON/MD/JAR), подсветка текущего 
  файла, авто-раскрытие пути к нему.
- **Поиск по всем файлам** workspace (Ctrl+Shift+F) с прогрессом и 
  подсветкой совпадений — работает на движке ripgrep, находит за доли 
  секунды даже в тысячах конфигов.
- **Доверенные папки** — приложение читает и записывает только в папки, 
  которые ты явно разрешил. При первом открытии или drag-and-drop папка 
  добавляется автоматически.
- **Личная папка** (`storage/`) для черновиков и экспериментов — открывается 
  кнопкой «Ctrl+N».
- **Защита от потери**: индикатор несохранённых изменений (`*`), 
  подтверждение при закрытии, авто-бэкап раз в 30 секунд, восстановление 
  после сбоя.

### Minecraft-специфика
- **Превью как в игре** — модалка, где текст отрисован с реальными цветами 
  и стилями, как он будет выглядеть в чате.
- **Шпаргалка кодов** — все 22 кода `&X` (цвета + форматирование) с 
  описанием и превью, клик вставляет в позицию курсора.
- **Поддержка MiniMessage-тегов**: `<color:red>`, `<red>`, `<gradient:a:b>`, 
  `<rainbow>`, `<bold>`, `<italic>`, `<underline>`, `<strikethrough>`, 
  `<obfuscated>`, `<reset>`, а также `<newline>`, `<click>`, `<hover>` и 
  прочие — они защищаются от форматирования и подсвечиваются в редакторе.
- **Валидация** — предупреждение в статус-баре, если в тексте есть 
  невалидные коды (`&z`, `&y` и т.п.).

### Внешний вид и UX
- **Светлая и тёмная темы**, 5 встроенных пресетов оформления + свои 
  пресеты с настройкой «применять только цвет/шрифт/размер» и т.п.
- **Системные шрифты** — полный список доступных на компьютере шрифтов с 
  превью.
- **Кастомизация** — акцентный цвет, размер шрифта интерфейса и редактора, 
  высота строк дерева, плотность (compact/normal/wide), положение тостов, 
  мини-карта вкл/выкл (отдельно для ввода и результата).
- **Кастомные хоткеи** — все действия настраиваются через UI, конфликты 
  разрешаются автоматически. Многоуровневый статус-бар показывает 
  доступные хоткеи в зависимости от зажатых модификаторов 
  (Ctrl → Ctrl+Shift → Ctrl+Alt → Ctrl+Shift+Alt).
- **Локализация** — русский и английский.

### Установка и обновление
- **Установщик** — MSI или NSIS-EXE, не требует установки зависимостей.
- **Автообновление** — приложение раз в сутки проверяет новые версии на 
  GitHub Releases. Если доступна новая — показывает модалку с описанием 
  изменений из `CHANGELOG.md`, скачивает и устанавливает в один клик 
  (без запуска установщика).
- **Подпись обновлений** — установщик подписан, приложение проверяет 
  подпись перед установкой (защита от подмены).

## Для кого

- **Владельцы Minecraft-серверов**, которые настраивают конфиги плагинов 
  (EssentialsX, LuckPerms, DeluxeMenus, CMI и т.п.) и хотят единообразный 
  стиль сообщений.
- **Разработчики плагинов**, которые тестируют локализацию без запуска 
  сервера.
- **Сборщики ресурспаков и датапаков**, работающие с текстовыми 
  компонентами.

## Технологии

- **Frontend**: React + TypeScript + Vite
- **Backend**: Rust + Tauri v2 (нативное приложение без Chromium, ~15 МБ)
- **Редактор**: CodeMirror 6
- **Парсинг**: `js-yaml`, `regex` (Rust)
- **Поиск**: `ignore` crate (движок ripgrep)

Приложение работает полностью офлайн, кроме проверки обновлений. Все данные 
хранятся локально — настройки в `localStorage`, рабочие файлы в папках, 
которые ты выбрал.
