# Security Policy

## Поддержка версий

Ниже будет приведён список версий, которые будут поддерживаться в поступающих обновлениях.

| Версия | Поддержка           |
| ------- | ------------------ |
| > 4.0   | :white_check_mark: |
| < 4.0   | :x:                |

## Почему не поддерживается версия ниже 4.0?
Это старый код, который был утерян в просторах моего компьютера. 
Так-же старая версия программы была написана на C++.
